# House Rules

A neon Las Vegas rail shooter by Miles Low / The Do Better Network.

Static site: `index.html` plus `assets/`. Deploys on Vercel with no build step.

- `assets/panels` story panels
- `assets/portraits` comms portraits
- `assets/models` 3D models (truck, bounty drone)
- `assets/skyline.jpg` Winners Dome skyline
